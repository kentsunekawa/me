# 自己紹介・人となり

## はじめに

はじめまして、常川と申します。

2016年にWeb業界に飛び込み、デザイン・Webフロントエンド開発・アプリ開発を含め約9年のフロントエンド開発者としての経験があります。

振り返ると、参画したプロジェクトには0からスタートするものやフルリニューアルのプロジェクトが多く、アーキテクチャ選定や開発環境の立ち上げから担当する機会が多くありました。

いただいた評価の中で最も印象に残っている言葉が「プロダクト開発を進める力がある」というものです。不確定要素が多い中で関係各所と連携・議論しながら物事を進める姿勢や、必要なことを自ら定義して解決しながら開発を推進するスタイルを端的に表してくれている言葉だと思っています。

---

## 強み

### アプリケーション開発を進める力

不確定要素の多い中でも、関係各所と連携・議論し、物事を決めながら開発を進めることが最大の強みです。プロジェクト立ち上げ段階からの参画や、組織やチームにとって一人目のエンジニアとして参画する中で培われました。

### デザインや Web 制作をベースとした UI 実装

グラフィックデザインや Web デザインの経験があり、UI/UX の開発においてエンジニアとしての視点だけではなくデザイン的な視点からの改善提案も得意とします。デザインが無い中での実装や、デザイナーの意図を汲み取った実装も強みの一つです。また Web 制作においては jQuery や Vanilla JS、SCSS を用いた制作経験も豊富にあるため、React や UI ライブラリに依存しない実装も可能です。

### 他領域へのインプット

開発をスムーズに進めることを目的として、隣接領域のスキルや知識のインプットに継続的に取り組んでいます。プライベートのプロジェクトを通して UI デザインと PHP / Laravel を用いたバックエンド API 開発を一通り経験し、アプリケーションを一つ開発した経験もあります。また、PdM やスクラムマスターとのコミュニケーションを円滑にするため、プロジェクトマネジメント領域の知識のインプットも行っています。

## 今後の展望

### バックエンド開発

バックエンドも含めた設計を行えるエンジニアになることを目指しています。コンピュータサイエンスや Web の基礎から、バックエンド開発のための言語・フレームワーク・データベースの技術習得ロードマップを作成し、学習を継続中です。フロントエンド領域で成果を上げることを前提としつつ、バックエンド領域へも徐々に染み出していきたいと考えています。

### グローバルな活躍

将来的に「日本国内」という枠にとらわれない、グローバルに活躍できるエンジニアを目指しています。書籍を用いた基本学習から、オンライン英会話などの実践的なトレーニングまで、継続的に英語力を磨いています。現時点では英語のドキュメントを読むスピードが大幅に向上しており、英語でのテキストコミュニケーションも行えるレベルになっています。
